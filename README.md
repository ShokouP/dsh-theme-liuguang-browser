# dsh-theme-liuguang-browser

Browser half of the **琉光 Liuguang** skin for the DeepSeek Harness GUI.

This package is installed automatically as a dependency of [`dsh-theme-liuguang`](https://www.npmjs.com/package/dsh-theme-liuguang); you normally do not install it by hand.

It mounts the frame-wide personalization overlay and the whale-girl pet, and serves `/liuguang/ping` plus the pet expression sprites.
